# dfm

Стандарт финансового моделирования **Data Fin Model (AFM&C)** как плагин
Claude Code: собрать книгу в Excel по контракту, проверить её и проверить
чужую.

Сервер не нужен. Плагин не обращается к API, не требует ключей и работает
полностью на стороне пользователя.

## Навыки

| Навык | Для чего |
|---|---|
| `/dfm:model-profile` | Какой профиль стандарта строим и что в нём неизменное ядро. **Читать первым** |
| `/dfm:model-book` | Состав книги, раскладка расчётного листа, `Structure`, формулы, оформление, `DEV_LOG` |
| `/dfm:model-dashboard` | Зоны дашборда, плитки KPI, диаграммы, слой агрегации на `Export` |
| `/dfm:model-audit` | Контроли, верификация, негативные тесты, аудит внешней модели |

Навыки вызываются моделью автоматически по контексту; явный вызов нужен
редко.

## Установка

Пока плагин не опубликован в маркетплейсе — из клона репозитория:

```bash
claude --plugin-dir ./plugins/dfm
```

## Что такое AFM&C

Agentic Financial Modelling & Controlling — три агентские роли поверх одного
стандарта модели: *Modelling* строит модель из документов и диалога, *Audit*
сверяет пакет документов между собой и с требованиями банка, *Controlling*
ведёт непрерывный план-факт и мониторинг ковенант.

Стандарт спроектирован как контракт между агентами: коды листов и именованные
диапазоны стабильны, поэтому внешний агент адресует модель, не разбирая
оформление. Спецификация допущений — `assumptions.v1`.

## Границы

Плагин учит строить и проверять книгу. Он **не** извлекает допущения из
документов, не парсит выписки и не ведёт версии наборов — это делает
платформа `data_fin_model` через API, и для неё будет отдельный контур.
