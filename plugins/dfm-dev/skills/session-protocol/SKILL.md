# Протокол сессии

## Сигнал конца блока — обязателен

Каждый блок работы закрывается ровно одной строкой:

| Сигнал | Когда |
|---|---|
| `Требуется push` | есть незапушенные изменения в рабочей копии |
| `Требуется миграция` | изменилась схема БД, нужен `alembic revision` / `upgrade` |
| `Ничего не требуется` | обсуждение, анализ, чтение — на диске ничего не поменялось |

Без этой строки пользователь не знает, есть ли у него незакрытый хвост.

## Токены сжатого языка

Пользователь пишет произвольным сжатым языком: смешение русского и
английского, пропуск пунктуации, ассоциативные переходы между темами в одном
сообщении. **Не переспрашивать формулировки** — разбирать намерение по
контексту. Уточнять только развилку, которая реально меняет результат.

Подтверждённые токены:

| Токен | Значение |
|---|---|
| `OM*` | начало сессии проекта |
| `ggwp` | текущая тема закрыта, переходим дальше |
| `BS` | режим мозгового штурма: точность вторична, гипотезы важнее, допустимы домыслы и неточные названия |
| `LG` | «доработай, продумай» — углубить проработку пункта, к которому приписан. Действует здесь и далее |

Токен относится к тому пункту сообщения, рядом с которым стоит, а не ко всему
сообщению.

## Конец сессии

Предложить, что стоит добавить или вывести в Claude Desktop / Claude Code,
исходя из скиллов и инструментов, которые реально понадобились в этой сессии.
Не список возможностей вообще — только то, чего не хватило по факту.

## Границы

MVP-first, критический путь из шести пунктов. Идея, которая его не приближает,
идёт в реестр инсайтов (`/dfm-dev:insights`), а не в работу. Расширение
области — только явным решением пользователя, не по инициативе Claude.
