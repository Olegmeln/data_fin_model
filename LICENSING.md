# Лицензирование / Licensing

Репозиторий состоит из трёх слоёв с разными лицензиями. Этот файл — карта:
какой путь под какой лицензией. При расхождении с заголовком отдельного файла
приоритет у заголовка файла.

*This repository is licensed in three layers. This file maps paths to
licences. A licence header inside a specific file takes precedence.*

---

## Слой 1. Контракт — открыт

Спецификация AFM&C: то, что внешний агент обязан знать, чтобы работать с
моделью. Открыт намеренно: стандарт, который запрещено реализовывать,
стандартом не станет.

| Путь | Лицензия |
|---|---|
| `docs/assumptions.v1.schema.json` | Apache-2.0 |
| `docs/Схема_v1.1_спецификация.md` | CC BY 4.0 |
| `docs/Профили_стандарта_и_выбор.md` | CC BY 4.0 |
| `spec/**` *(когда появится: профили `standard.v1`, референс-валидатор)* | Apache-2.0 |
| Коды листов и имена именованных диапазонов как таковые | Apache-2.0 (в составе схем) |

Apache-2.0 выбран вместо MIT из-за явного патентного гранта: принимающей
стороне — банку, фонду — это снимает вопрос о будущих претензиях.

Реализовывать спецификацию в своих продуктах, включая конкурирующие,
**разрешено**. Требуется указание авторства.

| Путь | Лицензия |
|---|---|
| всё остальное, в первую очередь `backend/**`, `api/**` | BSL 1.1 → Apache-2.0 через 4 года |

Код открыт для чтения, изменения и использования — включая работу
консультанта для своих клиентов. Запрещено одно: предлагать его третьим лицам
как размещённый сервис. Через четыре года после публикации каждая версия
автоматически становится Apache-2.0.

BSL — не Open Source лицензия в смысле OSI, и это указано в самом её тексте.

## Почему так

Три причины, по которым слои разведены:

1. **Стратегия требует открытой спецификации.** Цель — сделать
   `assumptions.v1` отраслевым стандартом. Закрытый стандарт не
   распространяется; открытый — единственный механизм, которым XBRL стал
   обязательным.
2. **Банку нужна проверяемость расчёта.** Аргумент «расчёт детерминированный,
   а не придуман нейросетью» работает, только если расчёт можно прочитать.
   BSL это даёт, не отдавая при этом хостинг конкурентам.
3. **Выручка не в секретности алгоритма.** NPV, аннуитет, сверка баланса —
   учебник. Актив — стандарт, корпус кейсов и размещённый сервис; их
   открытие кода не отнимает.
