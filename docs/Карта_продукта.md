# Карта продукта data_fin_model

Версия 0.2 — 12.06.2026. Живой документ: обновляется по мере развития продукта.
Изменения v0.2: интерактивный опросник с голосовым вводом; интейк по индустриальным
шаблонам; презентационная динамическая финмодель как премиум-модуль.

## 1. Видение

Финансовая модель перестаёт быть разовым файлом «на коленке» и становится живым организмом:
пользователь отдаёт продукту любые исходные данные, какие у него есть (выписки, таблицы,
документы, архивы), ИИ собирает из них качественную модель, а недостающее закрывается
прозрачными допущениями, которые со временем вытесняются фактом. Модель обновляется сама
из подключённых источников.

## 2. Два контура решения

### Контур A — «Личный» (самостоятельный пользователь)

**Для кого:** собственник малого бизнеса, ИП, основатель стартапа, самозанятый финансист.

**Работа, которую нанимают продукт делать (JTBD):** «Быстро и качественно собрать финмодель
из того, что у меня есть, не нанимая финдиректора, и чтобы она дальше жила сама».

**Ключевые механики:**

1. **Интерактивный опросник** — адаптивный диалог-онбординг с ветвлением вопросов
   (сфера → модель выручки → каналы продаж → команда → налоговый режим). Ответы можно
   давать голосом или текстом: распознанная речь превращается в структурированные
   параметры бизнеса. Результат опросника: выбранный индустриальный шаблон, стартовые
   допущения и персональный список данных, которые нужно загрузить.
2. **Интейк по индустриальным шаблонам** — шаблон отрасли задаёт слоты данных
   («банковская выписка», «ведомость ФОТ», «отчёт по продажам»): загрузка по слотам
   предсказуема и проще в отладке. Поверх слотов — свободная загрузка «кинул что есть»
   (PDF, Excel, CSV, TXT, 1С, ZIP): ИИ распознаёт тип каждого документа, парсит и
   нормализует. Недостающее запрашивается интеллектуально: продукт формулирует конкретную
   просьбу, а не абстрактное «загрузите данные».
3. **Карта полноты данных** — какие периоды и статьи закрыты фактом, где допущения,
   чего нет; из неё рождается следующий запрос данных.
4. **Движок допущений** — недостающие таблицы и выгрузки заменяются набором пользовательских
   допущений (средний чек, темп роста, доля ФОТ и т.п.). У каждого значения модели есть
   происхождение: факт / допущение / формула. Пришёл факт — допущение вытесняется,
   история сохраняется.
5. **Автообновление** — подключённые источники (банк, таблицы) обновляют модель по расписанию.

**Сценарий-эталон:** от регистрации до первой рабочей модели — 15 минут.

### Контур B — «Коммерческий» (масштабирование)

**Для кого:** компании с финкомандой, аутсорс-финдиректора и консультанты, ведущие
десятки клиентов, акселераторы и банки (витрина моделей).

**Что добавляется поверх контура A:**

- **презентационная динамическая финмодель** (см. раздел 7) — флагманский платный модуль;
- мультикомпании и рабочие пространства, роли и права;
- отраслевые шаблоны моделей и библиотека допущений;
- сценарии «что если» и сравнение версий модели;
- брендирование для консультантов (white-label), API платформы;
- дизайн как продуктовая фича: интерфейс уровня лучших мировых FP&A-инструментов,
  оптимальная структура модели «из коробки».

## 3. Путь пользователя (контур A, to-be)

| Шаг | Что происходит | Что делает ИИ |
|---|---|---|
| 1. Опросник | Интерактивный диалог с ветвлением; ответы голосом или текстом | Распознаёт речь, извлекает параметры бизнеса, подбирает индустриальный шаблон и стартовые допущения |
| 2. Загрузка по шаблону | Слоты данных отраслевого шаблона + свободная загрузка PDF/Excel/CSV/1С/ZIP | Распознаёт типы документов, парсит, нормализует; формирует интеллектуальный запрос недостающего |
| 3. Разбор | Операции разложены по статьям, дубли отсечены | Категоризация с уверенностью, выученные правила |
| 4. Карта полноты | Видно: что факт, что допущение, чего нет | Обновляет запрос данных после каждой загрузки |
| 5. Допущения | Мастер закрывает пробелы допущениями | Предлагает типовые значения по отрасли из шаблона |
| 6. Модель + дашборд | Живая финмодель: P&L, ДДС, план/факт; в премиуме — презентационная динамическая модель | Сводка и ответы на вопросы по цифрам |
| 7. Подключение источников | Банк по API / таблицы / регулярная загрузка | Обновляет факт, вытесняя допущения |

Боли as-is, которые закрываем: ручной перенос цифр из выписок; модель «устаревает» через месяц;
непонятно, каким цифрам верить; финдиректор дорог, шаблоны из интернета не сходятся.

## 4. Конкурентное поле

### Класс 1. Российские сервисы управленческого учёта
ПланФакт, Adesk, Финтабло, Финолог, Финансист, КУБ24, Finmap.

- Сильны: прямые интеграции с банками по API (Сбер, Т-Банк, Точка, Модульбанк, Альфа)
  и автозагрузка выписок для остальных; отчёты ДДС/ОПиУ/баланс; платёжный календарь;
  план-факт; мультиюрлица.
- Слабы для нашей задачи: это учёт «назад», а не моделирование «вперёд»; нет движка
  допущений и происхождения значений; не принимают произвольные документы (PDF-выписку
  или архив не разберут); модель нельзя забрать как таблицу.

### Класс 2. Глобальные FP&A-платформы
Causal, Runway, Finmark, Cube, Datarails, Mosaic, Fuelfinance, Pigment.

- Сильны: моделирование на драйверах, сценарии «что если», понятные формулы, красивые
  дашборды, AI-ассистенты; интеграции с QuickBooks/Stripe/CRM.
- Слабы для нашего рынка: цена от ~$500/мес и выше; нет 1С, русских банков и форматов;
  английский интерфейс; порог входа — нужен финансист.

### Класс 3. Excel / Google Sheets своими руками
Бесплатно, привычно, гибко — но всё вручную: перенос данных, формулы, поддержка.
До первых оборотов это «конкурент по умолчанию».

### Наша позиция
Между классами: **скорость и качество модели уровня FP&A-платформ + автоданные уровня
российских учётчиков + поверхность привычной таблицы.** Точки дифференциации, которых нет
ни у кого из трёх классов: голосовой опросник-онбординг, ИИ-инжест любых документов,
жизненный цикл «допущение → факт» и презентационная динамическая модель на выходе.

## 5. Дифференциаторы (что защищаем)

1. Онбординг-диалог с голосовым вводом: модель собирается «разговором», а не формами.
2. Инжест чего угодно: PDF, Excel, CSV, TXT, 1С, ZIP-архивы — один загрузчик на всё.
3. Происхождение каждого значения: факт / допущение / формула; допущения версионируются.
4. Карта полноты данных и автоматический интеллектуальный запрос недостающего.
5. Модель не чёрный ящик: живёт в Google Sheets / выгружается в Excel.
6. Презентационная динамическая финмодель — продукт, который не стыдно показать инвестору.

## 6. Индустриальные шаблоны (основа интейка)

Шаблон отрасли = статьи модели + слоты данных + стартовые допущения + ключевые KPI.
Фиксированный набор слотов делает загрузку предсказуемой — это упрощает отладку парсеров
и категоризации на реальных данных.

Стартовый набор для MVP (5 отраслей):

| Шаблон | Особенности модели | Типовые слоты данных |
|---|---|---|
| Услуги / агентство | проектная выручка, ФОТ — главная статья | выписка, ведомость ФОТ, список договоров |
| Розница / e-commerce | закупки, остатки, эквайринг, маркетплейсы | выписка, отчёт продаж, закупки, комиссии площадок |
| Общепит | фудкост, смены, средний чек | выписка, отчёт кассы, закупки продуктов |
| Подписки / SaaS | MRR, отток, юнит-экономика | выписка, отчёт биллинга, метрики подписок |
| Производство / опт | себестоимость, склад, отсрочки | выписка, закупки сырья, отгрузки, дебиторка |

Свободная загрузка «вне слотов» доступна всегда; ИИ сам определяет тип документа и
предлагает, к какому слоту его отнести.

## 7. Презентационная динамическая финмодель (премиум-модуль)

Более сложный и дорогой продукт поверх базовой модели. Четыре варианта реализации —
от быстрого к глубокому:

**В1. «Живая ссылка для инвестора»** — веб-страница с моделью и дашбордом: сценарные
ползунки (темп роста, средний чек, маржа, найм), графики пересчитываются на лету;
доступ по ссылке с паролем и сроком действия; брендирование; аналитика просмотров
(кто открыл, сколько смотрел, какие сценарии крутил). Быстрый «вау-эффект», минимальная
стоимость разработки — рекомендуемый старт.

**В2. «Финансовая презентация»** — автогенерация динамического дека: выручка и юнит-экономика,
структура затрат, сценарии A/B/C, потребность в финансировании и использование средств;
live-режим для показа на созвоне; экспорт в PDF/PPTX. Заменяет ручную сборку финслайдов
для питча.

**В3. «Data room-пакет»** — версия для due diligence: целостный Excel с работающими
формулами, журнал допущений с обоснованиями, версии модели, дашборд; следы изменений.
Продаётся проектно (разовая подготовка к раунду/кредиту).

**В4. «White-label для консультантов»** — брендированные презентационные модели для клиентов
консультанта или акселератора, библиотека шаблонов, массовое управление.

Монетизация: В1–В2 — верхний тариф контура B либо плата за активные ссылки/деки;
В3 — разовая услуга; В4 — партнёрский тариф. Дизайн здесь — главный фактор цены:
презентационный слой должен выглядеть на уровне продуктов мирового класса.

## 8. Уточнённый объём MVP

### Форматы данных на входе

| Формат | Статус | Примечание |
|---|---|---|
| CSV | Готово | автоопределение колонок и кодировок |
| Excel (.xlsx) | Готово | активный лист, та же карта колонок |
| 1С (1CClientBankExchange, .txt) | Готово | направление по счетам организации |
| ZIP-архив | Итерация 2 | распаковка, маршрутизация файлов по парсерам |
| PDF-выписки | Итерация 2 | табличные PDF топ-банков; сканы (OCR) — позже |
| Google Sheets как источник | Итерация 3 | выбор листа и диапазона |
| API банков | Итерация 3 | волна 1: Точка, Т-Банк (открытые API); волна 2: Модульбанк, Альфа, Сбер. Требуются ключи/заявки владельца счёта |

### Модули продукта (MVP)

Опросник (голос/текст) → индустриальные шаблоны и слоты → интейк и парсеры →
категоризация (правила + ИИ) → движок допущений → карта полноты данных →
финмодель (P&L, ДДС, план/факт) → дашборд → экспорт (Excel/PDF) → автообновление источников.

### Голосовой ввод: техническое решение

MVP — браузерное распознавание речи (Web Speech API: Chrome, Edge, Safari, русский язык
поддерживается, серверной части и оплаты не требует) с текстовым дублёром для остальных
браузеров. Следующий шаг — серверное распознавание (Whisper / Yandex SpeechKit) для
длинных голосовых ответов и мобильных приложений.

## 9. Метрики успеха MVP

- Время до первой рабочей модели ≤ 15 минут.
- ≥ 70% пользователей проходят опросник до конца; доля голосовых ответов — отслеживаем.
- ≥ 80% операций категоризированы без ручной правки.
- ≥ 70% значений модели закрыты фактом в течение 2 недель использования.
- Конверсия пробного периода в оплату; повторные загрузки данных ≥ 1 раза в неделю.

## 10. Бэклог разработки

### Итерация 2a — опросник и допущения
1. Интерактивный опросник с ветвлением и голосовым вводом (Web Speech API) →
   выбор индустриального шаблона, стартовые допущения, персональный список слотов данных.
2. Индустриальные шаблоны: 5 отраслей (статьи, слоты, допущения, KPI).
3. Движок допущений: происхождение значений (факт/допущение/формула), API допущений,
   вытеснение фактом, отображение в модели и на дашборде.

### Итерация 2b — расширенный интейк
4. ZIP-инжест: распаковка архива, обработка пачки файлов, сводный отчёт по каждому.
5. PDF-парсер банковских выписок (табличные PDF: Сбер, Т-Банк, Точка).
6. Карта полноты данных: покрытие месяцев и статей, интеллектуальный запрос недостающих
   выгрузок, виджет в интерфейсе.

### Итерация 3
Банковские API (Точка, Т-Банк), синхронизация по расписанию, Google Sheets как источник
и как носитель модели.

### Итерация 4 (контур B)
Презентационная динамическая финмодель: В1 «живая ссылка» → В2 «презентация»;
авторизация, мультикомпании и роли, сценарии «что если», отраслевая библиотека шаблонов.

## 11. Открытые вопросы

- Целевой рынок первой волны: РФ (банки и 1С это предполагают) — подтвердить.
- Ценообразование двух контуров; что входит в бесплатный уровень; цена презентационного модуля.
- OCR сканов и фото документов: какая итерация.
- Хранение и защита финансовых данных: требования, шифрование, сертификация — проработать до коммерческого запуска.
