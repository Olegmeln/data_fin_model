# Методология финансового моделирования — база знаний

Статус: каркас v0.1 — 25.07.2026. Живой документ (И-9): наполняется
исследовательскими сессиями, служит контекстом агентам M и A и основой
проверок валидатора. Каждый раздел имеет статус: ✅ проверено · 🔬 исследовать.

## 1. Принципы построения моделей (🔬 частично)

Выжимка признанных стандартов моделирования (FAST, SMART, ICAEW) — то, что
уже воплощено в движке, и то, что предстоит:

- **Разделение вводов и расчётов.** Вводы (синие) только в слое допущений;
  расчётные листы не содержат констант. ✅ реализовано: единый слой
  `assumptions.v1`, в книге вводы синим, формулы чёрным, ссылки зелёным.
- **Один ряд — одна формула.** Расчётная строка едина по всем периодам,
  без «особых» ячеек в середине ряда. ✅ движок генерирует ряды программно.
- **Сценарий — параметр, не копия.** ✅ И-3: overrides поверх базового набора.
- **Прозрачность цепочки.** Каждый показатель дашборда прослеживается до
  допущений; происхождение значений (факт/допущение/формула) хранится. ✅
- **Проверки целостности в самой книге.** Баланс А−П=0 строкой-формулой. ✅
  🔬 добавить: сходимость CF ↔ баланс по деньгам, контроль знаков.
- **Именованные ключевые ячейки** для внешних потребителей. ✅ контракт имён.

## 2. Требования банков РФ к финмодели заёмщика (🔬 исследовать)

Цель: чек-лист «модель, которую принимает кредитный комитет» → правила
валидатора при цели «банковское финансирование».

- 🔬 Собрать публичные методики/требования: Сбер (проектное финансирование),
  ВТБ, Альфа, РСХБ, ДОМ.РФ (стройка), ФРП (займы промышленности), корпорация
  МСП. Формат подачи, горизонты, обязательные формы (BS/PL/CF), помесячно/поквартально.
- 🔬 Типовые ковенанты и пороги: DSCR (обычно ≥ 1.2–1.5 в проектном
  финансировании), ICR, Долг/EBITDA, LLCR; собственное участие (обычно ≥ 20–30%).
  Зафиксировать источники по каждому банку.
- 🔬 Типовые причины возврата модели на доработку (для аудит-агента И-1).
- Уже в продукте: ковенанты DSCR/ICR/Долг-EBITDA с порогами и нарушениями,
  доля собственных средств в форме, чувствительность, помесячный CF.

## 3. Отраслевые бенчмарки допущений (🔬 исследовать)

Диапазоны «здравых» значений для генерации недостающих допущений (этап 4
конвейера) и проверок «выглядит нереалистично»:

| Отрасль | Ключевые бенчмарки для сбора |
|---|---|
| Услуги | ФОТ % выручки (35–50), маркетинг %, маржинальность |
| Розница/e-com | наценка/фудкост, доля комиссий площадок, оборачиваемость запасов |
| Общепит | фудкост % (25–35), аренда % выручки, средний чек по сегментам |
| SaaS | gross margin, CAC/LTV, отток, доля R&D |
| Производство | материалоёмкость, загрузка мощностей, нормы запасов |

🔬 Источники: РОССТАТ/ФНС (среднеотраслевые нагрузки), СПАРК-аналоги,
отчёты отраслевых ассоциаций, международные (Damodaran — маржи по отраслям).
Каждому бенчмарку — источник и дату среза.

## 4. Макропоказатели и источники (🔬 исследовать)

Для раздела `macro` схемы v1.1 (И-8):

- Ключевая ставка ЦБ РФ и прогнозная траектория (источник: ЦБ, обновление
  по заседаниям).
- Инфляция: факт Росстат, прогноз Минэк/ЦБ — для индексации цен и расходов.
- Курсы валют: ЦБ РФ; форвардные оценки для мультивалютных моделей.
- Налоговые расписания: НДС (20% → 22% с 2026 — проверить статус), прибыль,
  страховые взносы — уже поддержаны расписаниями в схеме.
- Ставка дисконтирования build-up: безрисковая (ОФЗ) + премии за размер,
  отрасль, страну. 🔬 методика и актуальные компоненты.

## 5. Методология оценки (✅ частично)

- NPV: помесячное дисконтирование FCFF после налога. ✅
- IRR: месячная → годовая. ✅ Ограничения IRR (несколько корней) —
  🔬 описать правила показа.
- MIRR с ROA реинвестирования (И-4). ✅ методологическое отличие от
  эталонных моделей — оформить как преимущество в материалах раунда.
- Окупаемость: простая по накопленному потоку. 🔬 добавить дисконтированную.
- DSCR/ICR/Долг-EBITDA — по годам. ✅

## 6. Кейсы и антипаттерны (🔬 пополняется из практики)

- Кейс «теплицы»: расхождения PDF ↔ XLSB (CAPEX, НДС, взносы) — эталонный
  тест аудит-агента; вывод: налоговые ставки — расписания, не константы. ✅
- Антипаттерн: сценарии копиями листов (7×CALCS) → рассинхрон формул. ✅ И-3.
